Linux内核框架（子系统）常见用户态命令行工具速查表

Linux 框架 / 子系统 常用工具 主要用途
V4L2 v4l2-ctl 查询摄像头、设置格式/FPS/曝光/增益、抓帧
v4l2-compliance 检查 V4L2 驱动接口是否规范
v4l2-dbg V4L2 驱动底层调试
v4l2-tracer 跟踪 V4L2 ioctl 调用
qv4l2 图形化控制 V4L2 设备
qvidcap 图形化视频采集
Media Controller media-ctl 查看/配置 Sensor→CSI→ISP→Video 拓扑
DRM/KMS modetest 查询 Connector、CRTC、Plane、显示模式
drm_info 查看 DRM 驱动和设备能力
kmscube 测试 DRM/KMS + EGL/GPU 显示
ALSA aplay 播放音频
arecord 录制音频
aplay -l / arecord -l 查看声卡设备
alsamixer 交互式调节音量/麦克风
amixer 命令行配置 Mixer
speaker-test 测试扬声器
GPIO gpiodetect 查找 GPIO Controller
gpioinfo 查看 GPIO line 信息
gpioget 读取 GPIO
gpioset 设置 GPIO
gpiomon 监听 GPIO 边沿事件
I²C i2cdetect 扫描 I²C 总线设备
i2cget 读寄存器
i2cset 写寄存器
i2cdump Dump 芯片寄存器
i2ctransfer 执行较复杂 I²C transaction
SPI spidev_test SPI 收发测试
IIO iio_info 查询 IIO 设备
iio_attr 读取/设置 IIO 属性
iio_readdev 读取传感器数据
iio_event_monitor 监听 IIO 事件
Input evtest 查看按键、触摸、鼠标等 input event
libinput list-devices 查看输入设备
libinput debug-events 实时查看输入事件
UART / TTY stty 设置波特率、数据位等串口参数
setserial 查看/配置串口
minicom 串口终端
picocom 轻量串口终端
CAN / SocketCAN ip 设置 CAN 接口、bitrate
candump 接收 CAN 报文
cansend 发送 CAN 报文
cangen 自动生成 CAN 报文
cansniffer 实时分析 CAN 数据变化
canplayer 回放 CAN 报文
USB lsusb 查看 USB 设备
lsusb -t 查看 USB 拓扑
usb-devices 查看详细 USB 信息
usbmon 抓取 USB 总线数据
Network ip 网卡、地址、路由、链路配置
ethtool Ethernet 网卡状态、速率、PHY
iw Wi-Fi 配置和状态
ss Socket/端口查看
tcpdump 网络抓包
ping 网络连通性测试
Block / Storage lsblk 查看块设备
blkid 查看 UUID、文件系统类型
fdisk 分区管理
parted 分区管理
mount / umount 挂载文件系统
smartctl 查看磁盘 SMART 信息
RTC hwclock 查看/设置硬件 RTC
rtcwake 利用 RTC 定时唤醒系统
Watchdog wdctl 查看 watchdog 状态
watchdog 用户态 watchdog daemon
LED /sys/class/leds/* 设置 LED 亮度、trigger
PWM /sys/class/pwm/* export、period、duty_cycle、enable
Thermal /sys/class/thermal/* 查看 SoC 温度、thermal zone
CPUFreq cpupower 查看/设置 CPU 频率和 governor
Device Tree dtc DTS ↔ DTB 编译转换
fdtdump 查看 DTB 内容
fdtget / fdtput 读取/修改 DTB 属性
Kernel Module lsmod 查看模块
modinfo 查看驱动模块信息
modprobe 加载/卸载及处理依赖
insmod / rmmod 直接加载/卸载 .ko
内核日志/设备管理 dmesg 查看内核日志
udevadm 查询和监控设备热插拔
lspci 查看 PCIe 设备
lsmod 查看当前内核模块
Linux 嵌入式
